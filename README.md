# 📚 Flashcard App

An interactive and responsive **Flashcard App** built using **HTML, CSS, and JavaScript**.

The application allows users to explore a collection of questions and answers through an interactive 3D flip-card interface.

## 🚀 Live Demo

🔗 https://vanshika2723.github.io/Flashcard-App/

## ✨ Features

* 🃏 Interactive 3D flashcard flip animation
* 📖 10 static question-and-answer cards
* ➡️ Next card navigation
* ⬅️ Previous card navigation
* 📊 Card progress indicator
* 📈 Animated progress bar
* 🎨 Modern gradient and glassmorphism UI
* 📱 Fully responsive design
* ⚡ Smooth animations and transitions
* 🚫 Navigation buttons automatically disable at the first and last card

## 🛠️ Technologies Used

* **HTML5** — Structure of the application
* **CSS3** — Styling, responsive design, gradients, glassmorphism, and 3D animations
* **JavaScript** — Flashcard data, navigation, card flipping, and progress tracking

## 💡 How It Works

1. The application starts with the first flashcard.
2. Click on the card to flip it and reveal the answer.
3. Use the **Next** button to move to the next question.
4. Use the **Previous** button to return to the previous question.
5. The progress indicator shows the current card number.
6. The progress bar updates automatically as you move through the deck.
